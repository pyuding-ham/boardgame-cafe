# 보드트립 기능명세서

보드게임 카페 소개와 이용후기 사이트의 기능 동작입니다. 운영 주소는 https://boardtrip.shop 입니다.

테이블 정의는 [schema.sql](schema.sql), 관계는 [erd.png](erd.png)를 봅니다. 실행 방법은 저장소 루트의 README를 봅니다.

## 사용자

| 구분 | 설명 |
| --- | --- |
| 비회원 | 로그인하지 않은 방문자 |
| 회원 | 가입 후 로그인한 사용자. `role`은 `USER` |
| 관리자 | `role`이 `ADMIN`인 회원 |

게임소개에 등록된 게임, 지점소개와 이용후기의 지점은 포트폴리오용 가상 데이터입니다. 지점 주소만 카카오맵 좌표를 만들려고 실제 지하철역을 넣었습니다.

## 접근 권한

목록과 상세 조회는 로그인 없이 가능합니다. 작성, 수정, 삭제, 댓글, 좋아요는 로그인이 필요합니다.

| 기능 | 비회원 | 회원 | 관리자 |
| --- | --- | --- | --- |
| 게임소개 작성·수정·삭제 | 불가 | 불가 | 가능 |
| 지점소개 작성·수정·삭제 | 불가 | 불가 | 가능 |
| 공지사항 작성·수정·삭제 | 불가 | 불가 | 가능 |
| 이용후기 작성 | 불가 | 가능 | 가능 |
| 이용후기 수정 | 불가 | 본인 글만 | 본인 글만 |
| 이용후기 삭제 | 불가 | 본인 글만 | 가능 |
| 댓글 작성 | 불가 | 가능 | 가능 |
| 댓글 수정 | 불가 | 본인 댓글만 | 본인 댓글만 |
| 댓글 삭제 | 불가 | 본인 댓글만 | 가능 |
| 좋아요 | 불가 | 가능 | 가능 |
| 문의 | 가능 | 가능 | 가능 |

이용후기 수정은 작성자 본인만 할 수 있습니다. 삭제는 작성자 본인과 관리자가 할 수 있습니다. 게임소개, 지점소개, 공지사항은 관리자면 다른 관리자가 쓴 글도 수정·삭제할 수 있습니다.

## 공통 규칙

- 화면에서 키 입력이나 10px 이상 마우스 이동이 없으면 60분 뒤 로그아웃하고 로그인 화면으로 보냅니다. 활동을 하면 이 시간은 다시 셉니다.
- 제목, 닉네임, 댓글은 출력할 때 태그를 글자로 바꿉니다.
- 게시글 본문은 에디터 HTML입니다. 저장할 때와 상세·수정 화면에서 읽을 때 허용된 태그만 남깁니다. 허용 태그는 제목, 굵게, 기울임, 밑줄, 취소선, 인용, 코드, 목록, 이미지, 표입니다.
- 게시글, 댓글, 회원 탈퇴는 `is_deleted`로 숨깁니다. 30일이 지나면 예약 작업이 행과 관련 파일을 지웁니다.

## 회원

### 회원가입

로그인하지 않은 사용자만 가입할 수 있습니다.

- 아이디는 4~20자의 영문, 숫자, 밑줄입니다. 중복되면 거절합니다.
- 이메일은 형식을 검사하고 중복되면 거절합니다.
- 비밀번호는 10자 이상이며 영문과 숫자를 모두 포함합니다. 특수문자는 `!@#$%^&*()_+-=[]{};':"\|,.<>/?` 만 사용할 수 있습니다.
- 비밀번호와 비밀번호 확인이 다르면 거절합니다.
- 성공하면 가입 완료 화면으로 이동합니다. 닉네임은 가입 처리에서 만들어 저장합니다.

### 로그인

- 아이디 또는 비밀번호가 비어 있으면 둘 다 입력하라고 알립니다.
- 10분 안에 비밀번호가 6번 틀리면 10분 동안 로그인을 막습니다.
- 이미 로그인한 상태에서 로그인 화면에 들어오면 메인으로 보냅니다.
- 자동 로그아웃으로 이 화면에 오면 세션을 지웁니다.

### 아이디 찾기

가입한 이메일을 입력하면 해당 아이디를 화면에 보여 줍니다. 메일은 보내지 않습니다. 없는 이메일이면 가입 정보가 없다고 알립니다.

### 비밀번호 재설정

가입한 이메일로 재설정 링크를 보냅니다. 없는 이메일이면 재설정 링크를 보내지 않습니다.

로그인 상태에서 비밀번호를 바꿀 때는 현재 비밀번호를 확인합니다.

두 경우 모두 비밀번호를 저장한 뒤 가입 이메일로 변경 완료 메일을 보냅니다. 메일 발송이 실패하면 로그만 남기고, 저장된 비밀번호는 되돌리지 않습니다. 변경 후에는 로그아웃하고 로그인 화면으로 이동합니다.

### 마이페이지와 회원정보

로그인한 회원만 들어갑니다.

- 닉네임은 2~12자입니다. 다른 회원이 쓰면 거절합니다.
- 이메일은 형식을 검사하고 다른 회원이 쓰면 거절합니다.
- 프로필 이미지는 1MB 이하입니다. 300×300으로 자른 뒤 WebP로 저장합니다.
- 바꾼 항목이 없으면 저장하지 않습니다.

### 회원 탈퇴

로그인한 회원만 탈퇴할 수 있습니다. 탈퇴하면 `is_deleted`와 `deleted_at`을 기록하고 로그아웃합니다. 30일 뒤 예약 작업이 회원 행과 프로필 이미지를 지웁니다.

## 게시판

게시판은 게임소개, 지점소개, 공지사항, 이용후기입니다. 게임소개 주소는 글 번호 대신 페이지 주소(슬러그)를 씁니다.

공통 검증은 다음과 같습니다.

- 제목은 필수이며 100자 이하입니다.
- 본문 글자 수는 태그를 뺀 기준 5,000자 이하입니다. 이용후기는 글자 없이 본문 이미지만 있어도 저장할 수 있습니다.
- HTML을 포함한 본문이 50,000바이트를 넘으면 거절합니다.
- 대표 이미지와 상세 이미지는 파일당 5MB 이하입니다. 가로·세로는 5,000px 이하입니다. jpeg, jpg, png, gif, webp만 됩니다. 상세 이미지는 최대 10장입니다.

작성에 성공하면 해당 게시판 목록으로 이동합니다. 수정에 성공하면 그 글의 상세 화면으로 이동합니다.

### 게임소개

관리자만 작성·수정·삭제합니다.

- 페이지 주소는 필수이며 255자 이하입니다. 영문이나 숫자를 포함해야 합니다.
- 카테고리는 필수입니다.
- 플레이 인원과 플레이 시간은 각각 20자 이하입니다.
- 해시태그는 255자 이하입니다.
- 난이도는 등록된 값만 선택할 수 있습니다.

목록은 카테고리와 난이도로 걸러 볼 수 있습니다.

### 지점소개

관리자만 작성·수정·삭제합니다. 주소는 필수이며 255자 이하입니다. 주소로 카카오맵 좌표를 저장하고 상세 화면에 지도를 보여 줍니다.

### 공지사항

관리자만 작성·수정·삭제합니다. 상단 고정이 가능합니다.

첨부파일은 최대 3개, 파일당 10MB입니다. 허용 확장자는 pdf, hwp, hwpx, doc, docx, xls, xlsx, ppt, pptx, txt, zip, jpg, jpeg, png입니다.

### 이용후기

로그인한 회원이 작성합니다. 수정은 작성자 본인만 할 수 있고, 삭제는 작성자 본인과 관리자가 할 수 있습니다. 지점 선택은 필수입니다. 목록은 지점으로 걸러 볼 수 있습니다.

목록의 본문 미리보기는 태그와 공백 문자를 제거한 뒤 250자까지 잘라 두고, 화면에는 한 줄만 보여 줍니다. 지점 라벨은 한 가지 색으로 표시합니다.

## 댓글

로그인한 회원이 게시글에 댓글을 씁니다. 비어 있으면 거절하고, 3,000자를 넘기면 거절합니다.

수정은 작성자 본인만 할 수 있습니다. 삭제는 작성자 본인과 관리자가 할 수 있습니다. 삭제해도 행은 바로 지우지 않고 `is_deleted`로 숨깁니다.

## 좋아요

로그인한 회원이 게시글의 좋아요를 켜고 끕니다. 같은 글에 같은 회원의 좋아요는 한 번만 저장됩니다.

## 문의

이름, 이메일, 문의 내용, 개인정보 수집 동의가 필요합니다. 연락처는 선택입니다.

- 이름은 20자 이하입니다.
- 이메일은 형식을 검사합니다.
- 연락처를 입력했다면 형식을 검사합니다.
- 문의 내용은 1,000자 이하입니다.
- 동의하지 않으면 보내지 않습니다.

성공하면 메인으로 이동합니다. 메일의 받는 사람과 보낸 사람은 SMTP에 로그인한 계정입니다. 문의자가 입력한 이메일은 본문에 넣습니다.

## 예약 작업

브라우저로 실행할 수 없고 서버의 PHP CLI로 실행합니다.

| 스크립트 | 동작 |
| --- | --- |
| `cron/cron_delete_soft_deleted.php` | 삭제한 지 30일이 지난 게시글, 댓글, 탈퇴 회원을 물리 삭제합니다. 게시글에 연결된 업로드 파일도 지웁니다. |
| `cron/cron_delete_logs.php` | 6개월이 지난 로그인 로그, 1년이 지난 비밀번호 변경 로그와 회원정보 변경 로그를 지웁니다. |
